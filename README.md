## Preface
Another required project of 42school. You'll learn to use your first graphic library and key management at the same time as having fun by creating your first 2D mini game. You choose all the atmosphere.
<br>
<br>

## 📜 Mandatory part
We need to manage window rendering, read a map and create the game algorithm including collision management. To "win" the game you need to collect all items on the map and then take the exit, you cannot take the exit if you didn't collect all items.
<br>
<br>

## ✅ Bonus part
You need to add ennemies, moving or not. Touching them makes you loose the game. You alse need to add sprite animations and display the number of character's mouvment.
<br>
<br>
